# Focus. — Productivity Dashboard

Дашборд продуктивности: задачи, календарь, заметки, Pomodoro и музыкальный плеер.
Чистый HTML/CSS/JS + Tailwind, данные хранятся в браузере (localStorage / IndexedDB).

## Возможности
- Задачи с категориями, фильтрами, поиском и редактированием (двойной клик)
- Календарь с отметками дней и фильтром по дате
- Pomodoro-таймер с настройкой минут и счётчиком сессий
- Плеер со своими треками (IndexedDB)
- Кастомизация: 6 готовых тем, акцентный цвет, фон (картинка / градиент / цвет), затемнение и размытие,
  прозрачность и размытие панелей, скругление углов, шрифты, размер текста, отключение анимаций
- Экспорт и импорт данных, PWA (работает офлайн, ставится как приложение)

## Запуск
Открой `index.html` через локальный сервер (например `npx serve`) или выложи папку на Netlify / GitHub Pages.
